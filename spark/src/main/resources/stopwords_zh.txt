# 中文停用词表（精简版 · 项目自建）
#
# 用途：C-SPK-03 特征工程的「停用词过滤」环节（详细设计 §4.8）。
# 读取方：com.tibet.tourism.spark.Cspk03Features（从 classpath 资源加载）
#
# 设计说明（答辩要点）：
#   1. 为什么自建而不是引入哈工大/百度等大词表？
#      本项目语料是旅游评论，短句为主、口语化强。通用大词表里大量词（如"一定""非常"）
#      在情感与主题分析中仍有信息量，全量剔除反而损失特征。
#      自建精简表覆盖"高频但无区分度"的词，规模可控、可解释、便于复现。
#   2. 分三类，便于说明过滤动机：
#      ① 通用虚词与代词  ② 口语填充词  ③ 旅游语料的平台词/无意义词
#   3. 每行一个词；# 开头为注释，空行忽略；自动去首尾空白与 UTF-8 BOM。
#   4. 单字词不在此表中——它们在分词后由"最小词长 ≥ 2"的规则统一过滤。
