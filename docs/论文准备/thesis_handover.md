### 2.2 不可违反的格式要求

**装订顺序（A §1）**：封面 → 中文摘要关键词 → 英文摘要关键词 → 目录 → 正文 → **谢辞** → 参考文献 → 附录

**页面（A §2）**：A4；页边距**上下左右各 2.5 cm**；行间距**固定值 20 磅**；章节标题**不单独设置行间距**

**页眉页脚（A §3）**：
- 封面：无页眉页脚页码
- 中文摘要 → 目录：页眉「桂林电子科技大学毕业设计（论文）报告用纸」；页脚**居中**罗马数字 I、II、III，**小五宋体**
- 正文起：**只有页眉**，页码在页眉**右侧**，格式「第几页 共多少页」

**标题层次（A §4）**：

| 层次 | 格式 |
|---|---|
| 章 `1  标题` | 一级，居左，**黑体四号**，数字与标题间**空半角两格**，段前段后 0.5 行 |
| 节 `1.1 标题` | 二级，居左，**黑体小四**，**空半角一格**，段前段后 0 行 |
| 条 `1.1.1 标题` | 三级，居左，**楷体小四**，段前段后 0 行 |
| 项 `（1）` `①` | **宋体小四**，段前段后 0 行 |

> **谢辞之前的正文各章不需要独立起页**（A §4）

**字体（A §5.5）**：正文中文**小四宋体**；全文**字母、数字用 Times New Roman**

**摘要（A §5.2）**：中文 **300-500 字**；"摘 要"**三号黑体居中、中间空两格**、与内容空一行；内容小四宋体；关键词**小四黑体顶格**、**3-5 个**、分号分隔、**外延大的在前**

**Abstract（A §5.3）**：三号 **TNR** 加粗居中；内容小四 TNR、**每段开头空四个字母**；`Key words：`小四加粗 TNR 顶格、与内容隔一行、**接排不留空格**、末词后**不打标点**

**目录（A §5.4）**："目录"**三号黑体居中、两字空四格**；独立成页；**2-3 层**；序号全部左对齐；一级黑体四号、二级黑体小四、三级楷体小四

**谢辞（A §5.6）**：**另起一页**；"谢 辞"**四号黑体居中、中间空两格**；**内容限 1 页**；小四宋体

**参考文献（A §5.7）**：**另起一页、放在正文后**；标题**黑体四号顶格**；**不少于 10 篇且要有外文文献**；按引用顺序；右上角方括号标注；作者写前三位余者"等"；中文五号宋体、外文五号 TNR；悬挂缩进 2 字符

**图表公式（A §6）**：
- **图题在下、表题在上**，序号与名称之间**一个空格**
- 一律**分章连续编号**：图 6-1、表 6-1、公式 (6-1)
- 图题表题公式编号**五号字**（中文宋体、英文数字 TNR）
- **表格一律三线表，不画内部框线，上下边线 1.5 磅**；表格内字体**五号**
- 跨页表格须在**上方右侧**标「**续表 X-Y**」
- 截图要清晰、字体**不超过四号**、**不能一页一图**；图与图题须同页

### 2.3 章节结构（B 规定，**不得改动**）

```

   1.4 论文结构
2  相关技术介绍          ← B 未规定下级小节，可自行拟定

   3.2 系统功能性需求分析   ← 需用例图

   4.1 系统架构设计         ← 需系统架构图
```

### 3.3 技术职责边界（开题报告第 35 行的正式界定）

- **Spark / MLlib / LDA**：负责大规模离线统计计算、情感分类基线、主题发现 → 回答"数据有多少、分布如何、整体情感与主题是什么"
- **DeepSeek**：负责细粒度语义理解、方面级评价、景点智能评价生成、对比解释、限定范围问答 → 回答"评论具体在说什么、游客在乎什么、如何用自然语言解释"
- **两者是基线与增强的关系，不是替代关系**
- **核心原则**：「**数据负责事实，DeepSeek 负责语义理解与自然语言解释**」
