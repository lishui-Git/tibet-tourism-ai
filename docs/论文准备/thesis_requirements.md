## 五、封面【明确规定 · 来源 A §5.1】

- 采用下发的统一封面，填写：论文题目、学生学号姓名、学院、专业、指导教师姓名职称。
- 题目应恰当、准确反映研究内容；**题目一般不超过 20 个汉字**。
- 封面题目用**三号字、加粗、宋体**；其余用**小三号字、宋体**。

> **⚠️ 需核对**：本项目论文题目《基于DeepSeek的西藏旅游景点智能评价与分析系统的设计与实现》为 **31 个汉字**，**超出"一般不超过 20 个汉字"的要求**。此点需确认（见 `thesis_issues.md` 问题 I-01）。

## 十二、论文中的图、表、公式【明确规定 · 来源 A §6】

### 12.1 通用要求

| 项目 | 要求 |
|---|---|
| 图题/表题 | 每个图片、表格均应有图题（图序+图名）、表题（表序+表名），**序号与名称之间有一个空格** |
| 同页 | **图片和图题、表题和表格要在同一个页面** |

| 位置 | **图题置于图的下方；表题置于表的上方**；公式编号用括弧括起写在**右边行末**，其间不加虚线 |
| 图题/表题/公式编号字体 | **五号字**；中文 **宋体**；英文、数字 **Times New Roman** |
| 独立排序 | 图、表、公式**顺序单独排序** |
| 截图要求 | 截图不要大小不一，要能看清图片和文字；截图字体不要太大，**不能超过四号字**；**不能一个页面就放一张图**；图片特别长时可**横排两张图**；注意背景颜色，排版紧凑美观 |

- **上下边线宽度 1.5 磅**；
- 表格内字体：**五号字**；
- **跨页处理**：需在跨页的表格**上方右侧**标出「**续表 X-Y**」（示例见表4-1）。

### 12.3 公式专项

- 文中引用公式时，一般用「见式（6-1）」或「由公式（6-1）」。
